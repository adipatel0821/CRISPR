The LLM call audit log is never persisted in production. system_architecture.md §5 says "All calls: ... logged to llm_calls (prompt hash, schema version, validation outcome, latency)". `_persist_llm_calls` reads `getattr(llm, "call_log", None)`, but the real `llm.client.LLMClient` keeps its records in `calls` (a list of CallRecord). The attribute is never found, so no row is written. The API test passes only because its fake client exposes `call_log`. This is a cross-module contract drift between Agent 2's client and Agent 4's API, which the test fake hides.
Privacy is not affected: the records are metadata only, and redaction is verified. But the audit trail the architecture promises is empty, and A-15 "all rows purged incl. llm_calls" is satisfied only trivially because the table never fills.

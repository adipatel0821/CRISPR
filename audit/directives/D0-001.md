Finding:
The contract's itemization identity is arithmetically inconsistent with the contract's own running example and with TILA. It states
`cash_price + taxes_title_fees + add_ons + trade_in_payoff − cash_down − trade_in_value = amount_financed + prepaid_finance_charges (financed)`.
The left-hand side is the amount paid on the consumer's behalf, which is the AMOUNT FINANCED (TILA: amount financed = principal − prepaid finance charge). The right-hand side as written is the note PRINCIPAL. On the reference case the identity is off by exactly the $500 financed PFC, so a faithful implementation returns checks.itemization = "fail" for the correct demo contract and for A-24's "$500 financed PFC" fixture. That would put a false warning or conflict on the main demo path.
Evidence:
audit/evidence/recompute_reference_case_output.txt, line "itemization residual = -500.00": 22000.00 + 1500.00 + 0 + 0 − 4000.00 − 0 = 19500.00 = amount_financed, while amount_financed + PFC = 20000.00 (contracts header: principal 20,000; AF 19,500; PFC 500 in the note). Agent 1's in-progress (UNVERIFIED) F00 itemization branch in .claude/worktrees/wf_81b5f792-674-1/backend/engine/principal.py already uses the correct form (itemized = AF; principal = itemized + financed PFC). So the engine and the contract text already disagree.
Required correction:
1) Publish a contract erratum/ADR in implementation/DECISIONS.md. The itemization check becomes `cash_price + taxes_title_fees + financed add_ons + trade_in_payoff − cash_down − trade_in_value = amount_financed` (within $1.00), equivalently `= principal − financed PFC` when only principal is known. Use one shared implementation (engine offer_checks), not separate ones in documents/ and engine/.
2) Add the expected itemization result ("pass") to backend/fixtures/reference_case.json.
Done when:
The ADR is recorded. The single itemization check returns "pass" on the reference case and "fail" when cash_price changes by more than $1.00. Documents and manual-offer code call the engine check instead of re-implementing it.
